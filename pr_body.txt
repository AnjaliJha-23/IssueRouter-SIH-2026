## What does this PR do?
Migrates the summariser backend to Groq and fixes NLP pipeline ingestion components to support end-to-end processing.

## How to test it
1. Ensure `.env` is setup with a valid `GROQ_API_KEY`.
2. Activate your virtual environment.
3. Run `python backend/test_pipeline.py` and verify all tests pass.
