## Brand & Style
The design system delivers an institutional yet forward-looking civic-tech experience designed for cross-sector collaboration between Government, Academia, Enterprise/CSR, and Citizens. It embodies clarity, accountability, agility, and public trust. 

The aesthetic is Modern Civic Functionalism: a precise, airy composition characterized by high scannability, crisp surface boundaries, deliberate whitespace, and purposeful role attribution. The interface rejects bureaucratic clutter in favor of focused task flows, transparent metrics, and modern enterprise-grade ergonomics.

## Colors
The color architecture establishes an accessible, high-contrast base balanced by a structured taxonomy for cross-sector actors.

### Core Canvas & Accents
- **Canvas Base**: `#F8FAFC` (Slate-50) creates an eye-comfort ground that reduces stark glare while preserving contrast.
- **Surface Crisp**: `#FFFFFF` for primary cards, tables, modal dialogs, and navigation panels.
- **Primary / Action**: `#2563EB` (Blue 600) drives primary CTAs, links, system states, and default focus treatments.
- **Deep Navy Base / Footers**: `#0F172A` (Slate-900) anchors persistent footers, high-authority institutional headers, and inverted system banners.
- **Subtle Surface Stroke**: `#E2E8F0` (Slate-200) for card borders, dividers, and input borders.

### Sector & Stakeholder Palette
Used specifically for badges, role filters, project tags, and contextual card headers:
- **Government**: `#2563EB` (Background tint: `#EFF6FF`, border: `#BFDBFE`)
- **University & Research**: `#16A34A` (Background tint: `#F0FDF4`, border: `#BBF7D0`)
- **Industry & CSR**: `#F97316` (Background tint: `#FFF7ED`, border: `#FED7AA`)
- **Citizen & Non-Profit**: `#9333EA` (Background tint: `#FAF5FF`, border: `#E9D5FF`)

### Functional Feedback
- **Destructive / High Priority**: `#DC2626` (Red 600)
- **Warning / Under Review**: `#D97706` (Amber 600)
- **Resolved / Verified**: `#16A34A` (Green 600)
- **Informational / Triage**: `#0284C7` (Sky 600)

## Typography
The system employs **Plus Jakarta Sans** for headlines and high-impact structural titles to deliver a progressive, humanized civic authority. **Inter** handles dense data grids, body copy, and UI controls for maximum legibility at small sizes and high optical fidelity across varied display panels.

Headings strictly employ tabular-compatible kerning adjustments, and body text maintains generous vertical clearance (1.4–1.5 line-height ratio) to streamline comprehension of technical problem descriptions and administrative workflows.

## Layout & Spacing
The layout follows an 8-point harmonic spacing cadence on an adaptive 12-column responsive grid.

- **Desktop (1024px and up)**: 12 columns, 24px gutters, maximum container bounds of 1280px (`80rem`). Page margin defaults to dynamic centering with a minimum safe margin of 32px.
- **Tablet (768px – 1023px)**: 8 columns, 20px gutters, 24px horizontal side margins. Complex sidebars collapse into persistent drawer overlays or stacked secondary tabs.
- **Mobile (320px – 767px)**: 4 columns, 16px gutters, 16px lateral padding. Card decks stack vertically in single columns, with primary filters accessible via bottom sheets.

## Elevation & Depth
This design system rejects heavy or muddy dropshadows, relying instead on clean surface separation, low-contrast ghost strokes, and soft ambient ambient diffusion tinted with cool slate.

- **Flat / Canvas (Level 0)**: Background `#F8FAFC`. Zero elevation.
- **Resting Surface (Level 1)**: Base cards, list panels, and textareas set against `#F8FAFC` use a pure `#FFFFFF` background bound by a single 1px border of `#E2E8F0` with a soft ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Raised / Hover Cards (Level 2)**: Interactive issue cards, dropdown menus, and hover states subtly elevate: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`, with border transitioning to `#CBD5E1`.
- **Floating Overlays (Level 3)**: Modals, slide-in triage panels, and flyouts: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`, layered over an `#0F172A` backdrop at 40% opacity with a 4px backdrop blur.

## Shapes
Geometry uses clean, balanced curvature:
- **Base Components (Inputs, Buttons, Dropdowns)**: `0.75rem` (12px) for an approachable, refined modern tool feel.
- **Cards & Data Modules**: `0.875rem` to `1rem` (14px – 16px) bounding boxes providing generous containment for status badges and sector tags.
- **Dialogs & Large Containers**: `1rem` (16px) with clean cutaways.
- **Status Pills & Role Badges**: `9999px` (Full Pill) to differentiate administrative tags from structural interface buttons.

## Components

### Buttons
- **Primary**: Background `#2563EB`, text `#FFFFFF`, border-radius 12px, font weight 600. Hover: `#1D4ED8`. Active: `#1E40AF`. Focus-visible: 2px ring `#2563EB` offset by 2px white.
- **Secondary / Ghost-Outline**: Background `#FFFFFF`, border `1px solid #CBD5E1`, text `#0F172A`. Hover: `#F1F5F9`, border `#94A3B8`.
- **Tertiary / Subdued**: Background transparent, text `#475569`. Hover: background `#F1F5F9`, text `#0F172A`.
- **Destructive**: Background `#DC2626`, text `#FFFFFF`. Hover: `#B91C1C`.

### Sector Tags & Status Chips
Pill-shaped containers (`height: 24px` or `28px`, rounded `9999px`) with an explicit semantic role:
- **Government Pill**: Background `#EFF6FF`, border `1px solid #BFDBFE`, text `#1D4ED8`.
- **University Pill**: Background `#F0FDF4`, border `1px solid #BBF7D0`, text `#15803D`.
- **Industry/CSR Pill**: Background `#FFF7ED`, border `1px solid #FED7AA`, text `#C2410C`.
- **Citizen Pill**: Background `#FAF5FF`, border `1px solid #E9D5FF`, text `#7E22CE`.
- Chips always prefix with a matching 6px circular indicator dot or sector icon.

### Form Inputs & Selectors
- Height `44px` on desktop, `48px` on mobile for optimal touch targets.
- Background `#FFFFFF`, 1px border `#CBD5E1`, border-radius 12px, padding `0 14px`.
- Focus state: border-color `#2563EB`, paired with a 3px soft outer ring of `rgba(37, 99, 235, 0.15)`.

### Issue & Innovation Cards
- Background `#FFFFFF`, border `1px solid #E2E8F0`, border-radius 16px, padding `20px`.
- Structure: Header row containing the Sector Badge + Submission Date; Center body containing title (`headline-sm`), brief description (`body-md`), and impact category; Footer containing upvote/endorsement tally, stakeholder count, and status pill (e.g., *Under Review*, *Matched*, *Funded*).
- Interaction: Gentle lift on hover with `Level 2` shadow and border shift to `#CBD5E1`.

### Data Tables & Civic Metrics
- Header row: `#F8FAFC` background, 1px bottom border `#E2E8F0`, uppercase `label-sm` text in `#64748B`.
- Row styling: `#FFFFFF` background, hover highlight `#F8FAFC`, transition duration 150ms. Cell padding `14px 16px`.

### Footers & Institutional Anchors
- Background `#0F172A` (Dark Navy), body text `#94A3B8`, headings `#FFFFFF`.
- Micro-dividers: `#1E293B`. Form controls within dark surfaces adopt `#1E293B` background with `#334155` border and `#FFFFFF` text.
